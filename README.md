### 💡 Project Overview
**Kiwi Reborn** is a maintenance-focused fork of the original Kiwi Browser. The primary goal of this project is to ensure the browser remains modern and secure without changing the core experience users love.

> [!IMPORTANT]  
> This is a fork of the original Kiwi repository. It is specifically updated to keep **Chromium** current and ensure **Android API support** is up to date. No unnecessary features have been added to keep it lightweight.

---

### 🛠 What's New?
*   **Updated Chromium Engine:** Better security and compatibility with modern websites.
*   **Latest Android SDK:** Optimized for the newest versions of Android.
*   **Bug Fixes:** Keeping the original source stable and usable.
